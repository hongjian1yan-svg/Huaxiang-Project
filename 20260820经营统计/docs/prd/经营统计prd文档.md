### 0.1 面积字段对照（校验用）


| 稿面用语             | 落地字段          | 说明                        |
| ---------------- | ------------- | ------------------------- |
| 土地面积（证载面积）/ 校验上限 | **证载建筑面积**    | 室外车位、新增/编辑房产、维护摊位等校验的上限字段 |
| 已有土地的「土地面积」取值    | **证载面积**      | 已有土地记录中，土地面积取【证载面积】       |
| 室内车位「房屋面积」       | **所属房屋**的房屋面积 | 不扣减该房屋下已有室内车位             |




### 0.2 摊位与房屋/车位关系

- **单个摊位面积 = 该摊位下房屋面积 + 车位面积**（摊位已包含房屋与车位）
- 涉及「摊位相加」的校验与区域汇总：**只对摊位面积求和**，不要再把房屋、车位面积单独加一遍

## 1. 经营统计 · 面积口径调整

- 页面：经营统计

### 1.0 统计范围与示意数字

- **未选中某一区域时**：面积概览（及摊位统计 / 总览情况等总览数据）展示**当前市场全部**汇总。
- **选中某一区域时**（如点击地图 A 区）：展示**该区域**的总览（面积概览等切换为 A 区汇总）。
- 设计稿中的面积数字**仅为展示参考**，不作为真实相加结果，也不作为验收依据；实现以业务口径与主数据汇总为准。
- 区域面积：子区域 = 该区域内**摊位面积**之和；总区域 = 各子区域之和（因摊位已含房屋+车位，不再额外叠加房屋/车位面积）。



### 1.1 面积概览 · 收起态（默认）

设计稿中**第一个**「面积概览」模块为收起态，展示三项（单位均为 ㎡）：


| 指标   | 口径             |
| ---- | ------------------- |
| 区域面积 | 新增。按摊位面积层层汇总（见 1.0） |
| 房屋面积 | 新增。取值【资产管理-房产管理】    |
| 车位面积 | 新增。取值【资产管理-车位管理】    |


「房屋面积」「车位面积」旁有「数据详情」入口；「区域面积」无该入口。

### 1.2 「数据详情」交互（页内展开）

点击「数据详情」后，**模块在页内直接下拉展开**，不跳转其他页面。设计稿纵向三态示意：


| 设计稿模块顺序 | 状态   | 说明                   |
| ------- | ---- | -------------------- |
| 第一个面积概览 | 收起   | 仅三项总览（1.1）           |
| 第二个面积概览 | 房屋展开 | 点击房屋「数据详情」后的展开态（1.3） |
| 第三个面积概览 | 车位展开 | 点击车位「数据详情」后的展开态（1.4） |


收起 / 展开后仍保留顶部三项总览，明细行追加在模块下方。

### 1.3 房屋面积 · 展开态


| 指标     | 口径                       |
| ------ | ------------------------ |
| 待租房屋面积 | 取值【资产管理-房产管理】            |
| 已租房屋面积 | 取值【资产管理-房产管理】            |
| 自用房屋面积 | 房屋侧自用面积（与「自用车位面积」不是同一字段） |
| 公共设施面积 | 使用性质为「公共设施」的房屋面积汇总       |




### 1.4 车位面积 · 展开态


| 指标     | 口径                                                    |
| ------ | ----------------------------------------------------- |
| 待租车位面积 | 取值【资产管理-车位管理】                                         |
| 已租车位面积 | 取值【资产管理-车位管理】                                         |
| 自用车位面积 | **系统已有字段**，本期在经营统计中**新增展示**；与「自用房屋面积」相互独立，不是同一口径的对称字段 |




### 1.5 摊位统计 / 总览情况 / 地图


| 模块   | 说明                                   |
| ---- | ------------------------------------ |
| 摊位统计 | 摊位总数、已出租 / 未出租 / 临到期；「数据详情」**本次不改动** |
| 总览情况 | 合作商户、有效合同、合同金额；「数据详情」**本次不改动**       |
| 地图   | 分区展示；悬停可看区域明细；**点击某区**后总览切换为该区数据     |

## 2. 土地管理 · 房产总面积 / 车位总面积

- 页面：资产管理 → 土地管理 → 编辑土地

### 2.1 表单新增字段


| 字段    | 必填  | 交互           |
| ----- | --- | ------------ |
| 房产总面积 | 是   | 占位「请填写房产总面积」 |
| 车位总面积 | 是   | 占位「请填写车位总面积」 |




### 2.2 已有土地数据

- 对**目前已有的土地管理列表**，系统自动计算【房产总面积】【车位总面积】并填入
- 已有土地的「土地面积」取值：**取【证载面积】**



### 2.3 校验

- 规则：`房产总面积 + 车位总面积` **不能大于**【证载建筑面积】
- 超出时，在输入框下提示：**房产总面积+车位总面积不能大于证载建筑面积**

## 3. 车位管理 · 车位面积校验（新增/编辑）

- 页面：资产管理 → 车位管理 → 新增车位 / **编辑车位**（逻辑相同）


| 车位类型 | 触发条件            | 校验规则                                 | 失败提示              |
| ---- | --------------- | ------------------------------------ | --------------------- |
| 室外   | 输入车位面积          | 本车位面积 + 已有车位面积 + 已有房屋面积 ≤ **证载建筑面积** | 已超出可使用的土地面积，请重新输入车位面积 |
| 室内   | 已选【所属房屋】且输入车位面积 | 本车位面积 ≤ **所属房屋**的房屋面积（全量，不扣减已有室内车位）  | 已超出可使用的房屋面积，请重新输入车位面积 |


编辑车位与新增车位**同一套校验**（编辑时「本车位面积」按保存后的该条面积参与计算，勿把本条旧值重复计入「已有」）。

## 4. 房产管理 · 建筑面积校验（新增/编辑）

- 页面：资产管理 → 房产管理 → 新增房产 / **编辑房产**（逻辑相同）


| 项        | 内容                                               |
| -------- | ------------------------------------------------ |
| 触发       | 输入 / 修改建筑面积                                      |
| 规则       | 本房产建筑面积 + 已有车位面积 + 已有房屋面积 ≤ **证载建筑面积**           |
| 失败提示 | 已超出可使用的土地面积，请重新输入建筑面积                            |
| 适用范围     | 新增与编辑同一逻辑；使用性质为「公共设施」时**同样适用本规则**（公共设施属于房屋面积的一种） |

## 6. 摊位信息管理 · 维护摊位面积校验


| 项        | 内容                                   |
| -------- | ------------------------------------ |
| 触发       | 维护摊位时修改【摊位面积】                        |
| 规则       | 该摊位面积 + 该地块**其余摊位面积**之和 ≤ **证载建筑面积** |
| 求和范围     | **仅摊位面积相加**（因每个摊位已包含房屋+车位，不再另加房屋/车位） |
| 失败提示 | 已超出可使用的土地面积，请重新输入摊位面积                |

## 7. 前端需求摘要

- 经营统计：面积概览按 1.1–1.4；未选中=全市场，选中区域=该区总览；自用车位面积本期展示
- 菜单统一【经营统计】
- 土地：房产总面积 / 车位总面积必填，校验相对证载建筑面积
- 车位 / 房产：新增与编辑同一校验；公共设施同房产建筑面积校验
- 维护摊位：摊位面积之和相对证载建筑面积
- 使用性质「公共设施」走 PC 字典；列表/筛选同步
- 摊位统计、总览情况的「数据详情」本次不改

视觉按花乡 `设计规范/PC/`。

---



## 8. 后端需求摘要

- 区域 / 子区域按**摊位面积**汇总；选中区域过滤；未选中全市场
- 房屋类 / 车位类指标分别从房产管理、车位管理汇总；自用车位面积用已有字段输出
- 已有土地：土地面积取证载面积；回填房产总面积、车位总面积；保存校验相对证载建筑面积
- 车位室外 / 房产（含公共设施）/ 摊位：占用校验上限均为证载建筑面积
- 车位室内：相对所属房屋面积（全量）
- 新增与编辑同一校验逻辑
- 使用性质「公共设施」由字典配置
