# PRD：数据中心 · 商户排名统计

- 所属系统：花乡商管 PC（市场端管理后台）
- 所属模块：数据中心 / 商户排名统计
- 需求类型：排名统计报表
- 涉及端：PC
- 真源：预览页 `preview/数据中心.html`
- 文档状态：已确认

## 1. 入口

数据中心 → 商户排名统计。

## 2. 筛选

| 字段 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 所属市场 | 下拉 | 空 | 为空时展示全部市场 |
| 统计时间 | 日期范围 | 本月 1 日至当天 | 查询所选周期的商户统计数据 |

提供查询、重置、查询数据导出。重置后恢复全部市场、本月时间和【全部】Tab。

## 3. 排名维度

使用位于筛选模块上方的 Tab 切换排名依据，默认选中【全部】：

| Tab | 排序规则 | 单位 |
| --- | --- | --- |
| 全部 | 不排序，展示筛选市场下全部商户 | — |
| 入库量 | 从高到低 | 辆 |
| 周转周期 | 从短到长 | 天 |
| 出库量（过户） | 从高到低 | 辆 |
| 出库金额 | 从高到低 | 万元 |

切换 Tab 后保留筛选条件并回到第 1 页。Tab 文案在默认、选中及 hover 状态下均使用黑色；排名维度对应的列表字段仍用花乡绿色突出。

周转周期暂按所选周期内完成过户车辆，从入库时间到过户时间的平均天数计算。

### 全部 Tab 汇总

仅在【全部】Tab 展示汇总模块，指标按 4＋3 两行排列：车商总数、入库总数、上架总数、出库总数、平均周转周期、出库总金额、平均出库金额。

- 车商总数：筛选结果中的商户数量。
- 入库总数、上架总数、出库总数：筛选结果对应字段合计。
- 出库总金额：筛选结果中的出库金额合计。
- 平均周转周期：按商户出库量加权计算。
- 平均出库金额：出库金额合计 ÷ 出库总数。

每项指标右侧上下展示环比、同比：环比对比上月同期，同比对比去年同期，增长率为 `(本期值 - 对比期值) ÷ 对比期值 × 100%`。上涨使用红色上箭头，下降使用绿色下箭头，持平使用灰色横线，百分比保留两位小数。当前预览使用模拟百分比，后续由接口返回真实对比数据。

## 4. 列表

| 列名 | 说明 |
| --- | --- |
| 排名 | 按当前 Tab 排序后的连续名次 |
| 所属市场 | 商户所属市场 |
| 商户名称 | 商户名称 |
| 入库量 | 所选周期车辆入库量 |
| 周转周期 | 所选周期完成过户车辆的平均周转天数 |
| 出库量（过户） | 所选周期完成过户的车辆数量 |
| 出库金额 | 所选周期完成过户车辆的金额合计 |

【全部】Tab 列表展示：序号、所属市场、商户名称、入库总数、上架总数、出库总数、平均周转周期、出库总金额、平均出库金额。其中平均出库金额为该商户出库总金额 ÷ 出库总数；车商总数仅作为页面汇总指标，不在单个商户行内重复展示。

其余排名 Tab 列表始终同时展示入库量、周转周期、出库量（过户）、出库金额四项指标，当前 Tab 对应字段仅改变排序和视觉强调。

【入库量】Tab 在入库量后增加新车、二手车两列，两项数量合计等于入库量；在出库金额后增加出库金额（新车）、出库金额（二手车）两列，两项金额合计等于出库金额。列表仍按入库量从高到低排序。

入库量表头右侧展示上下双箭头，默认按入库量从多到少；点击后切换为从少到多，再次点击恢复。反向排序只改变列表展示顺序，排名仍按入库量从多到少计算；重置恢复默认倒序。

### 各排名维度前三名

【入库量】【周转周期】【出库量（过户）】【出库金额】Tab 均在筛选模块与列表之间单独展示前三名。第 1 名居中靠上，第 2 名位于左下，第 3 名位于右下，每项使用对应名次徽章。

- 入库量：展示商户名称、入库量及新车/二手车数量。
- 周转周期：展示商户名称、周转周期及出库量（过户）。
- 出库量（过户）：展示商户名称、出库量（过户）及出库金额。
- 出库金额：展示商户名称、出库金额及出库量（过户）。

各维度前三名仍保留在下方完整列表中，不从列表中剔除或重复计算排名。

前三名展示始终按入库量从多到少取值，不随下方列表正序/倒序切换而改变。

## 5. 导出

导出当前筛选条件及排名维度下的全部数据，字段顺序与当前 Tab 列表一致。

## 6. 本期范围

本期不增加图表和商户详情页；汇总卡片仅在【全部】Tab 展示。
