# PRD：数据中心 · 移库车辆明细统计

- 所属系统：花乡商管 PC（市场端管理后台）
- 所属模块：数据中心 / 移库车辆明细统计
- 需求类型：数据统计报表（筛选 + 汇总 + 列表）
- 涉及端：PC
- 真源：预览页 `preview/数据中心.html`
- 文档状态：已确认

## 1. 入口与范围

- 入口：数据中心 → 移库车辆明细统计
- 页面包含筛选、汇总指标、列表和分页。

## 2. 筛选

| 字段 | 控件 | 选项 / 格式 | 默认 |
| --- | --- | --- | --- |
| 所属市场 | 下拉 | 市场列表 | 空 |
| 所属车商 | 下拉 | 车商列表 | 空 |
| 车辆类型 | 下拉 | 全部、新车、二手车 | 全部 |
| 支付方式 | 下拉 | 全部、2SC账户支付、扫码支付 | 全部 |
| 操作人 | 下拉 | 操作人列表 | 空 |

筛选条件同时作用于汇总指标和列表；点击查询后页码回到第 1 页，重置恢复默认值。

## 3. 数据展示

| 指标 | 单位 |
| --- | --- |
| 移库车辆 | 辆 |
| 移库车辆（新车） | 辆 |
| 移库车辆（二手车） | 辆 |
| 移库服务费 | 元 |

## 4. 列表

车辆移库时间展示格式为 YYYY-MM-DD HH:mm:ss。列表字段按以下顺序展示：

序号、所属市场、车辆移库时间、车商名称、车辆信息、车辆类型、车辆价格、移库服务费（元）、支付方式、操作人、操作。

其中车辆信息展示车型、车架号，车架号前显示“车架号：”；序号按当前列表从上到下连续递增；操作列展示绿色可点击的详情文案，打开右侧移库车辆详情页。“移库车辆信息”展示列表对应字段，并增加备注、移至车商、联系电话、所在车位；下方“车辆信息”展示车型、车架号、车辆类型、车辆价格；详情不展示序号。

## 5. 导出

导出当前筛选条件下的全部列表数据，不含操作列；导出字段与列表字段对应，车辆信息拆分为车型、车架号。

## 6. 文案

- 菜单 / 页面：移库车辆明细统计
- 筛选标签：所属市场、所属车商、车辆类型、支付方式、操作人
- 指标：移库车辆、移库车辆（新车）、移库车辆（二手车）、移库服务费
