# 补打价签明细统计 PRD

## 1. 页面范围

入口：数据中心 → 补打价签明细统计。页面复用花乡 PC 统计报表结构：筛选、汇总指标、明细列表、分页与查询数据导出。

## 2. 筛选

| 字段 | 控件 | 选项 |
| --- | --- | --- |
| 所属市场 | 下拉 | 市场列表 |
| 所属车商 | 下拉 | 车商列表 |
| 车辆类型 | 下拉 | 全部、新车、二手车 |
| 支付方式 | 下拉 | 全部、2SC账户支付、扫码支付 |
| 经办人 | 下拉 | 经办人列表 |

筛选条件同时作用于汇总指标和明细列表。搜索字段与下方按钮分行时保持 20px 间距。提供【查询】【重置】【查询数据导出】。

## 3. 汇总指标

共 4 项，单行展示：

1. 补打车辆
2. 补打车辆（新车）
3. 补打车辆（二手车）
4. 补打金额

## 4. 明细列表

| 列名 | 说明 |
| --- | --- |
| 序号 | 按当前列表从上到下连续递增 |
| 所属市场 | 车辆所属市场 |
| 补打价签日期 | 车辆补打价签时间，展示格式为 YYYY-MM-DD HH:mm:ss |
| 车商名称 | 车辆所属车商 |
| 车辆信息 | 展示车型、车架号 |
| 车辆类型 | 新车 / 二手车 |
| 车辆价格 | 车辆价格，单位万元 |
| 补打金额 | 补打价签金额，单位元 |
| 支付方式 | 2SC账户支付 / 扫码支付 |
| 经办人 | 补打操作经办人 |
| 操作 | 绿色文字【详情】；点击打开当前行详情 |

分页每页 10 条。车辆信息列展示车型、车架号并保持单行完整展示；车辆类型、车辆价格、补打金额、支付方式、经办人列按内容收窄，操作列保持紧凑。

## 5. 交互与规范

- 页面新增左侧子菜单【补打价签明细统计】。
- 页面样式复用【换证车辆明细统计】及《花乡 PC 端设计规范》：品牌色、筛选区、指标卡、表格、分页与导出按钮保持一致。
- 点击列表【详情】打开右侧详情抽屉，样式参照换证车辆明细详情页。上方“补打价签信息”展示所属市场、车商名称、补打金额、支付方式、经办人、车商负责人、联系电话、经办人电话、备注；下方“车辆信息”单独展示车型、车架号、车辆类型、车辆价格；详情不展示序号。
- 预览数据仅用于页面展示，不作为真实统计口径。
