## 操作与角色差异

### 意向线索

Figma 已标注：

| 角色 | 已见操作 |
| --- | --- |
| 销售角色 | 查看、认领线索、新增跟进 |
| 管理员 / 超管 | 查看、分配线索、认领线索、新增跟进、删除 |

- 新增跟进弹窗：全部字段必填，保存后详情增加跟进记录。
- 分配线索弹窗：先选角色再选员工，单选且全部必填，分配后详情增加跟进记录。

### 买车线索与卖车线索

截图可见列表操作包含「查看」与「更多操作」。YAN 已确认买车线索、卖车线索使用与意向线索一致的更多操作能力，具体展示受下方状态映射控制。

现有资料尚未确认买车线索、卖车线索上述操作的角色权限差异和操作结果。

### 三类线索按跟进状态展示操作

YAN 已确认买车线索、卖车线索、意向线索共用以下状态—操作映射：

| 跟进状态 | 更多操作菜单 |
| --- | --- |
| 待跟进 | 分配线索、认领线索、删除 |
| 跟进中 | 新增跟进、删除 |
| 完成跟进 | 删除 |
| 跟进失败 | 删除 |
